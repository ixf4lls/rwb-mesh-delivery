# Тестовые наборы

Данные синтетические; seed по умолчанию 42. Счётчики позиций — число строк заказа, а не суммарное количество единиц. ID сущностей хранятся как строки только из цифр, чтобы одновременно выполнять числовой формат и OpenAPI `type: string`. Читаемые коды и имена вынесены в нормализованные справочники. Товарные измерения — только `width_m`, `height_m`, `depth_m` (метры); площадь и объём не рассчитываются и не сохраняются.

## Нормализованные таблицы

Справочники `cities.csv`, `points.csv`, `sellers.csv`, `seller_skus.csv`, `categories.csv`, `districts.csv` и `nodes.csv` связывают числовые ID со строковыми кодами и отображаемыми именами. Факты содержат только цифровые ID/FK; корзины в `orders.csv` ссылаются на numeric-string `product_id`. Для сценариев 1–5 общие атрибуты трёх продавцов и 12 SKU описаны в [shared/catalog_scenarios_1_5.json](shared/catalog_scenarios_1_5.json); локальные ID остаются уникальными для набора.

Каждая папка набора включает `manifest.json` с row counts и SHA-256 и `expected.json` с контрольными сценариями. Поля `contract`, `schema`, `direction` сохраняются в API-примерах.

## Команды

Из корня репозитория:

```bash
python3 scripts/datasets.py generate <id> --seed 42
python3 scripts/datasets.py validate [id]
python3 scripts/datasets.py estimate russia10_full
```

`dense` генерирует вместе `peak`, чтобы сохранить идентичный спрос. Полный Russia10 запускается отдельно и вне репозитория:

```bash
python3 scripts/datasets/agents/russia10.py full --seed 42 --days 7 --out /private/tmp/russia10_full
python3 scripts/datasets/agents/russia10.py validate /private/tmp/russia10_full
```

В окружении нет Parquet writer-а, поэтому факты записываются в CSV. Первичная оценка составляла около 9,5 ГБ. Фактический полный набор занял 6 141 151 409 байт (5,72 ГиБ); проверка подтвердила numeric-only IDs, нормализованные ссылки, геометрию, 146 937 точка-дней, 29 396 863 заказа и 88 201 968 позиций. Набор не включён в репозиторий.

Во всех таблицах `points.csv` присутствуют рейтинг ПВЗ (`rating`, 1.0–5.0 с точностью до десятых), загруженность (`load_level`: низкая/средняя/высокая) и вместимость (`capacity_cells`, целое число ячеек).
