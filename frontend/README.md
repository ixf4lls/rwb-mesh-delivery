# RWB Mesh Delivery Frontend

Для запуска нужен Node.js 20.19+ в 20-й ветке или Node.js 22.12+.

Из папки `frontend`:

```sh
npm ci
npm run dev
```

Стартовая страница `/` ведёт в кабинет ПВЗ (`/pvz`), кабинет продавца (`/seller`) и модель доставки (`/delivery-model`). На этапе инициализации эти страницы проверяют маршрутизацию и доступны без сервера API.

`npm run typecheck` генерирует типы из `../docs/openapi/frontend.yaml` и проверяет TypeScript. `npm run build` дополнительно собирает приложение в `dist`. При размещении сборки настройте возврат `index.html` для маршрутов приложения.

Клиент использует `/api/v1`. Для отдельного сервера задайте `VITE_API_BASE_URL` в `frontend/.env.local`. Провайдер авторизации передаёт токен в клиент через `createAppStore({ getAccessToken })`. При смене пользователя создайте новый store или очистите кеш API. Клиент уже описывает запросы сессии, демозапуска и статуса команды.
