Разрабатывай frontend на React + TypeScript, соблюдая следующие правила:

1. Используй отступы в 4 пробела во всех файлах фронтенда.
2. Не добавляй лишние комментарии в коде.
3. Используй CSS Modules. CSS должен быть чистым, читаемым, без комментариев, с пустой строкой между блоками селекторов.
4. Выноси логику компонентов в кастомные хуки в папку hooks.
5. Вспомогательные функции выноси в папку functions. Используй чистые функции без мутации исходных данных.
6. Компоненты размещай в папке components. Для каждого компонента создавай отдельную папку, например Product/Product.tsx и Product/Product.module.css.
7. Переиспользуй компоненты: кнопки, поля ввода, модальные окна и другие повторяющиеся элементы.
8. Не перегружай компоненты логикой. Разделяй логику и отображение.
9. Используй простую и понятную JSX-разметку: div, Fragment и стандартные HTML-элементы. Избегай section и aside без необходимости.
10. Используй понятные названия переменных, функций и компонентов.
11. Избегай дублирования кода, избыточных абстракций и неоправданно сложных решений.

Код должен быть простым, чистым, структурированным и понятным студенту, который сможет самостоятельно объяснить его работу.
